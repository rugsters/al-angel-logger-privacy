# Al Angel Logger Privacy Policy

**Effective date:** September 13, 2026  
**Last updated:** September 13, 2026

This Privacy Policy explains how **Al Angel Logger** (the **Bot**) accesses, uses, stores, and deletes information received through Discord. By adding or using the Bot in a Discord server, server administrators acknowledge the practices described below.

## 1. Purpose of the Bot

Al Angel Logger provides server administrators with configurable moderation and audit logs. Administrators choose which event categories are enabled and which Discord channels receive the resulting logs. The Bot does not moderate users automatically, sell data, serve advertising, or create user profiles for commercial purposes.

## 2. Information the Bot processes

Depending on the features enabled by a server administrator, the Bot may process:

- Discord server, channel, role, message, webhook, invite, event, and user identifiers;
- member information such as usernames, display names, nicknames, role membership, join time, boost status, membership-screening status, avatar identifiers, and member flags;
- moderation and server events, including joins, departures, bans, timeouts, role or nickname changes, channel changes, voice-state changes, AutoMod events, and audit-log activity;
- message information such as content, embeds, attachments, components, polls, references, mentions, edit history, deletion time, author, and channel;
- server configuration, logging destinations, ignore lists, retention settings, and operational status information; and
- limited technical records required to operate the Bot, diagnose errors, and deliver configured logs.

The Bot does not request or use Discord presence data. It does not collect passwords, payment-card information, or authentication codes.

## 3. How information is used

Discord API data is used only to provide the Bot's stated moderation, audit-log, history, troubleshooting, and configuration features. Message data may be temporarily cached so that authorized server administrators can review a message after it is edited or deleted. Eligible attachments may be cached and re-uploaded to a configured moderation-log channel after deletion.

The Bot does **not** use message content or other Discord API data to train machine-learning or artificial-intelligence models. Data is not used for advertising, data brokerage, eligibility decisions, or unrelated user profiling.

## 4. Storage and retention

The Bot stores operational data on infrastructure controlled by the Bot operator, including a SQLite database and a local attachment cache. Access is restricted to the Bot operator and authorized infrastructure administrators.

Cached messages and attachments use a server-configurable retention period from 1 to 365 days; the default is 30 days. Attachments may be removed earlier when configured storage limits are reached. Username, nickname, and avatar history defaults to 365 days. Deleted invite records are retained for up to 7 days. When the Bot leaves a server, that server's stored data is scheduled for complete deletion after 30 days.

Data may be deleted earlier when it is no longer needed for the configured functionality, when Discord requests deletion, or following a valid request from the affected user. Server administrators may also exclude selected channels, users, or roles from logging and may purge cached server messages and attachments through the Bot's settings.

## 5. Data sharing

The Bot does not sell Discord API data or share it with advertisers, data brokers, or analytics providers. Data is sent back to Discord only as necessary to post the logs and responses configured by authorized server administrators. Data may be disclosed when required by law or when necessary to protect users, the Bot, or the security of the service, subject to applicable law and Discord's terms.

## 6. User choices and deletion requests

Server administrators can use the Bot's configuration and ignore controls to determine which supported events are logged and to exclude channels, users, or roles. They can also purge cached messages and attachments for their server.

A Discord user may request access to, correction of, or deletion of API data associated with them by joining the official support server at [discord.gg/angel](https://discord.gg/angel) and contacting the support staff. Requests should include the user's Discord user ID and the relevant server ID so the operator can locate the applicable records. Do not send passwords, authentication codes, or other sensitive credentials. The operator may ask for reasonable verification that the requester controls the relevant Discord account.

Valid requests will be handled as promptly as reasonably possible, subject to legal obligations and the need to protect other users' rights. Some server audit records may also exist as Discord messages in administrator-selected log channels; management of those Discord-hosted messages remains under the control of the applicable server administrators.

## 7. Children's privacy

The Bot is intended only for people who are permitted to use Discord under Discord's Terms of Service and applicable law. The Bot is not directed to children below the minimum age required to use Discord.

## 8. Security

The operator uses reasonable administrative and technical safeguards intended to protect stored data against unauthorized access, loss, alteration, or disclosure. No storage or transmission system can be guaranteed to be completely secure. If a data incident occurs, affected users and Discord will be notified when required by law or Discord's Developer Terms.

## 9. Changes to this policy

This policy may be updated when the Bot's features or data practices change. The effective date at the top of this page will be revised when material changes are published. Continued use of the Bot after an update is subject to the revised policy.

## 10. Contact

For privacy questions or data requests, join the official Al Angel support server at [discord.gg/angel](https://discord.gg/angel) and contact the support staff.
